## Refleksi

### 1. Platform mana yang paling menarik untuk dipelajari? Mengapa?

Menurut saya, platform Web adalah platform yang paling menarik untuk dipelajari karena bisa digunakan untuk membuat berbagai macam website sesuai kebutuhan. Contohnya adalah website toko online, website sekolah, sistem informasi kampus, dan portofolio pribadi. Saya tertarik mempelajari Web karena hasilnya bisa dibuka melalui browser tanpa harus menginstal program khusus terlebih dahulu. Selain itu, saya ingin memahami proses membuat website dari awal, mulai dari menyusun struktur halaman menggunakan HTML, mengatur tampilan dengan CSS, sampai menambahkan fungsi menggunakan JavaScript. Menurut saya, belajar Web cukup menyenangkan karena perubahan yang dibuat bisa langsung dilihat hasilnya. Kalau sudah memahami dasar-dasarnya, saya ingin mencoba membuat website sederhana sendiri, lalu menambahkan fitur sesuai kebutuhan. Kemampuan ini juga bisa membantu saya mengerjakan tugas kuliah dan membuat proyek pribadi. Saya merasa pengetahuan tentang Web akan berguna karena banyak kegiatan sekarang dilakukan melalui website. Karena itu, saya ingin terus berlatih agar lebih memahami cara membuat website yang rapi, mudah digunakan, dan bermanfaat bagi orang lain.

### 2. Apa tantangan terbesar saat setup environment?

Menurut saya, tantangan terbesar saat melakukan setup environment adalah memastikan semua tools yang dibutuhkan sudah terpasang dan dapat digunakan dengan benar. Setelah instalasi, saya perlu memeriksa setiap program melalui terminal, misalnya dengan menjalankan perintah `git --version`, `node --version`, `npm --version`, dan `java -version`. Saya juga perlu memahami cara menghubungkan pekerjaan di komputer dengan repository GitHub. Bagian Git dan GitHub cukup menantang karena ada beberapa perintah yang memiliki fungsi berbeda. Saya harus memahami kapan menggunakan `add`, `commit`, dan `push` agar perubahan file tersimpan dan bisa muncul di repository. Selain itu, saya perlu memastikan folder yang dibuka di terminal sudah benar supaya file tugas tidak tersimpan di lokasi yang salah. Jika muncul pesan kesalahan, saya harus membaca dan memahami pesannya terlebih dahulu. Menurut saya, proses ini membutuhkan ketelitian dan latihan, terutama karena saya masih membiasakan diri menggunakan beberapa tools tersebut. Tantangan utamanya bukan hanya memasang program, tetapi juga memahami cara menggunakannya untuk mengerjakan tugas.
