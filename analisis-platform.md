# Analisis Perbandingan Platform Web, Desktop, dan Mobile

## 2. Tabel Perbandingan Platform

| Aspek           | Web                                                                                      | Desktop                                                                                     | Mobile                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| Bahasa utama    | HTML, CSS, JavaScript                                                                    | Java, C#, C++, Python                                                                       | Kotlin, Java, Swift                                                                    |
| Arsitektur      | Biasanya menggunakan sistem client-server dan dijalankan melalui browser                 | Berjalan langsung pada sistem operasi komputer                                              | Berjalan pada sistem operasi HP atau tablet, seperti Android dan iOS                   |
| Cara distribusi | Pengguna bisa mengaksesnya melalui browser menggunakan alamat website                    | Biasanya dibagikan dalam bentuk file installer atau melalui toko aplikasi                   | Bisa diunduh melalui Play Store, App Store, atau dipasang dengan cara lain yang sesuai |
| Keunggulan      | Mudah diakses dari berbagai perangkat tanpa harus memasang aplikasi khusus               | Bisa memanfaatkan kemampuan komputer dan cocok untuk berbagai kebutuhan pekerjaan           | Mudah digunakan di mana saja dan bisa memanfaatkan fitur HP, seperti kamera dan GPS    |
| Keterbatasan    | Beberapa fitur bergantung pada browser dan layanan tertentu membutuhkan koneksi internet | Perlu memperhatikan kecocokan dengan sistem operasi dan terkadang harus melakukan instalasi | Terbatas oleh kapasitas baterai, ukuran layar, dan perbedaan spesifikasi perangkat     |
| Contoh aplikasi | Google Docs versi web                                                                    | Microsoft Word versi desktop                                                                | WhatsApp versi Android                                                                 |
